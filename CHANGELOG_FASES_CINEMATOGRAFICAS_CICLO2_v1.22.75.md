## 🎯 Objetivo

Transformar los desastres del Ciclo 2 de mecánicas simples a **experiencias cinematográficas épicas** con:
- **5 fases progresivas** en lugar de 3 simples
- **Efectos visuales masivos** (partículas, sonidos, títulos)
- **Dificultad escalada dramáticamente** en cada fase
- **Fase CRÍTICA devastadora** antes del declive
- **Mantener fase INICIO como base** (no cambiar dificultad inicial)

## 📝 Notas Técnicas

### Estructura de Fases

```java
private int getFaseActual(double progreso) {
    if (progreso < 0.15) return 1;       // INICIO
    else if (progreso < 0.35) return 2;  // FASE 2
    else if (progreso < 0.60) return 3;  // PICO
    else if (progreso < 0.75) return 4;  // CRÍTICO
    else return 5;                        // DECLIVE
}
```

### Detección de Cambio de Fase

```java
int faseAnterior = getFaseActual(progreso - 0.01);
int faseActual = getFaseActual(progreso);

if (faseActual != faseAnterior && faseActual >= 2) {
    activarEfectoTransicionFase(faseActual);
}
```
